# 🌍 AI Air Quality Monitoring Dashboard

A real-time AI-powered Air Quality Monitoring Dashboard built using Machine Learning, Streamlit, Weather API, and Data Analytics.

---

## 🚀 Features

- 🌍 Live GPS Location Detection
- ☁ Real-Time Weather Integration
- 📊 Interactive Pollution Analytics
- 🤖 Machine Learning Prediction
- 🌫 PM2.5 Forecasting
- 📈 Dynamic Charts & Visualizations
- 🌙 Professional Dark UI
- 🏥 Health Recommendations
- 🌐 Dynamic City Detection

---

## 🛠 Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Plotly
- OpenWeather API
- Machine Learning
- Random Forest Regressor
